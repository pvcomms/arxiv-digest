# arxiv-digest

The README that shipped with this repo said it ran on Claude Opus with
ephemeral prompt caching, and quoted a cost of about three cents for the first
digest and a tenth of that afterwards. None of that was true by the time anyone
read it. The git log says why: commit `37803c2`, "docs: real README — live URL,
stack, cost numbers, why", landed first. Commit `6964a60`, "swap Opus → Gemini
2.5 Pro for cost", landed after it, and nobody went back to the prose. The
`.env.example` still asked for an `ANTHROPIC_API_KEY`, which the code has never
once read.

I rewrote the README against the code instead of against the last README. Here
is what it actually does.

## The pipeline

Paste an arXiv URL into the box. `parseArxivId` pulls the id out with a regex
that handles `/abs/`, `/pdf/`, and `/html/` forms plus bare ids, strips the
version suffix, and hands it to `export.arxiv.org/api/query`. That returns an
Atom feed — for "Attention Is All You Need" the whole document is 2,965
characters — which `fast-xml-parser` turns into a title, an author list, a
publication date, category tags, and an abstract.

The abstract is the entire input to the model. For that same paper it is 1,136
characters, 166 words.

The server then opens a server-sent-events stream and calls `gemini-2.5-pro`
through `@google/genai`, with a 3,374-character system prompt describing six of
my projects, five standing theses, and a ranked list of the six paper topics I
care about. The user block asks for strict JSON: a verdict of `must-read`,
`worth-skimming`, or `skip`, a two-sentence summary, a placement in the
landscape, concrete hooks into named projects, things to steal, the honest
counter-argument, and open questions. Tokens stream back one SSE `token` event
at a time and the browser parses the accumulated text into the typed shape as it
arrives.

From there you can branch. Three kinds: go deeper on one methodological
subsection, diff the paper against a related one, or argue the sharpest
implication for exactly one project and name something to build or abandon in
two weeks. Each branch carries its parent's body along as context, so depth
compounds. The tree persists to `localStorage` keyed by paper id, undo holds ten
steps, and the whole thing exports as indented markdown.

## What it cannot do

It never reads the paper. The `pdfUrl` field is captured from the feed and
rendered as a link in the header, and that is the only thing that ever happens
to it. No PDF is fetched, no full text is parsed, there is no PDF library in the
dependency tree. Every verdict, every "steal this algorithm", every branch four
levels deep into a method is generated from 166 words of abstract and the
model's prior knowledge of the paper. When it tells you about the authors'
experimental design, it is reconstructing, not reading. That is the single
biggest limitation and no amount of branch depth fixes it.

"Compare to related paper" is three hardcoded papers. `SEED_RELATED` maps
exactly three arXiv ids — the transformer paper, Constitutional AI, and a
prediction-markets paper — each to one hand-written neighbour. Every other paper
in existence falls through to a stub titled "Adjacent work in cs.LG" that points
back at the paper you started from, and the model then dutifully writes a
compare-and-diff essay against nothing. The code's own comment admits this is
waiting for a vector search that was never wired up.

There is no prompt caching anywhere. The 3,374-character stack context is resent
in full on every root digest and every branch. It is not expensive, but the
90%-savings claim in the old README described an implementation that does not
exist.

The streaming path asks for JSON in the prompt and nowhere else. Only
`/api/digest/route.ts` sets Gemini's `responseMimeType: "application/json"` —
and that route is unreachable, 96 lines of dead code the UI never calls. The
live path relies on the model behaving, and a client-side parser that returns
null and silently renders raw text when it does not.

Without a key nothing errors. `hasGeminiKey()` falls through to `streamStub`,
which types out four canned sentences on a 35ms cadence. It looks exactly like a
working digest until you read it. `@anthropic-ai/sdk` is still listed as a
dependency with zero imports.

## Running it

```bash
pnpm install
cp .env.example .env.local   # GEMINI_API_KEY — not ANTHROPIC_API_KEY
pnpm dev
```

`pnpm build` compiles in 3.6s on Next.js 16.2.4 with Turbopack and needs no
secrets: one static page, three dynamic API routes. I did not run a live digest
while writing this, because I do not have a Gemini key on this machine, so
nothing here describes output I have not seen generated by code I read.

1,691 lines across fourteen files, and it still only reads the abstract.
